---
title: "IDE サポート"
description: "Vespa は、IDE でスキーマとランクプロファイルを扱うためのプラグインを提供しています:"
---

- VSCode: [VS Code 拡張機能](https://marketplace.visualstudio.com/items?itemName=vespaai.vespa-language-support)
- Cursor、code-server、その他の VS Code 互換 IDE: [Open VSX レジストリの VS Code 拡張機能](https://open-vsx.org/extension/vespaai/vespa-language-support)
- IntelliJ、PyCharm、WebStorm: [Jetbrains プラグイン](https://plugins.jetbrains.com/plugin/18074-vespa-schema-language-support)
- Vim: [neovim](https://blog.vespa.ai/interns-languageserver/#neovim-plugin)

複雑な Vespa アプリケーションを扱う場合は、プラグインのインストールを強く推奨します!
