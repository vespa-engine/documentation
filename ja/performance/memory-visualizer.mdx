[スキーマ](/ja/basics/schemas)は、フィールド、フィールドの型、フィールドごとの設定を定義します。例:

```js expandable
schema product {

    document product {

        field productId type long {
            indexing: summary | attribute
            attribute: fast-search
            rank: filter
        }

        field description type string {
            indexing: summary | index
        }

        ...
    }
}
```

フィールドの型は多くの場合アプリケーションのデータによって決まりますが、フィールドの*使われ方*も重要です - 例:

- ユース・ケースが許せば、フィールドがサマリー・フィールドやインデックス・フィールドであり得る場合でも、メモリー書き込みのみの属性を使用することで、ドキュメントの高速な更新を実現できます
- アクセスが等価比較("price < 100" のような範囲ではない)であれば、文字列フィールドは数値フィールドより高速な場合があります

要するに、機能・パフォーマンス・コストのトレードオフがあります。リソース使用量の見積もりに役立つガイドがあり、[属性](/ja/content/attributes)を参照できますが、データ内の一意な値の数などの要因が分からないことも多いでしょう。むしろ、データを Vespa Cloud にフィードし、オンラインでスキーマを変更してその効果を観察する方が簡単な場合もあります。Vespa Cloud には、このプロセスを加速する 2 つの機能、メモリー・ビジュアライザーと自動再インデックスがあります:

<Frame>![メモリー・ビジュアライザー](/assets/img/memory-visualizer-1.png)</Frame>

メモリー・ビジュアライザーを使用すると、属性フィールドをブラウズして、絶対サイズと相対サイズを観察できます。これは、メモリー律速のアプリケーションにおけるコスト要因を特定し、最適化のためのボトルネックを見つけるのに役立ちます。

メモリー・ビジュアライザーは、コンソールのアプリケーションの「services」ビューにあります。"documentation (type: search)" タイプのノードをクリックし、*Memory visualizer* リンクを使用します。

## フィールドの追加または変更

フィールドを追加する際には、メモリー・ビジュアライザーを使用してメモリーを追跡します。属性フィールド、インデックス・フィールド、サマリー・フィールドは、空のフィールドとメモリー使用量に関して、データ型に応じて異なる振る舞いをします - このツールは、評価を支援するために、追加データのための余裕(ヘッドルーム)を示します。

移行中のデータ可用性を考慮したスキーマ変更の計画には、[フィールド変更手順](/ja/operations/self-managed/procedure-change-attribute-index)を使用してください。コンソールには再インデックスの進捗が表示されます:

<Frame>![再インデックスの進捗](/assets/img/reindex-progress.png)</Frame>

これにより、再インデックスの完了時期を簡単に見積もることができます。属性のメモリー使用量については、すべてのデータ構造が解放されるためにノードの再起動が必要になる場合があることに注意してください。再度メモリー・ビジュアライザーを使用する際には、この点に留意してください。

## ビジュアライザーの使用

一部のフィールドは異なる色分けがされています。フィールドの種類を理解するには、[コンテント・ノードのデータ構造](/ja/content/proton)を参照してください - 要点は次のとおりです:

- `Ready` は、インデックス済みのドキュメントで、クエリーに含まれる場合と含まれない場合があります
- `Not Ready` は、ノードに保存されているドキュメントのレプリカで、後でインデックスされる可能性があります
- `Removed` は、削除されたドキュメントです。アプリケーションによって削除されたか、ドキュメントのレプリカが別のノードに移動された場合です
- `Documentmetastore` は、ドキュメント ID のマッピングです - [属性](/ja/content/attributes#document-meta-store)を参照してください
