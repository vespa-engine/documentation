---
title: "RAG ブループリント"
---

Vespa は、Perplexity のような大規模 RAG アプリケーションにとって
[選ばれるプラットフォーム](https://blog.vespa.ai/perplexity-builds-ai-search-at-scale-on-vespa-ai/)です。
必要な機能はすべて揃っていますが、それらを組み合わせるのは容易ではないこともあります。

このオープンソースのサンプル・アプリケーションには、次のような RAG アプリケーションを作成するために必要なすべての要素が含まれています

* 最先端の品質を提供し、かつ
* あらゆる量のデータ、クエリー負荷、複雑さにスケールする。

この README では、ブループリントに基づいて独自のアプリケーションを作成・実行する手順を説明します。
より詳しい説明は [RAG ブループリントのチュートリアル](/ja/learn/tutorials/rag-blueprint.html)を参照するか、
[Python ノートブック](https://vespa-engine.github.io/pyvespa/examples/rag-blueprint-vespa-cloud.html)を試してみてください。

セットアップ:

<Steps>
<Step>
**Vespa Cloud に[テナント](/ja/learn/tenant-apps-instances)を作成します:**
	[console.vespa-cloud.com](https://console.vespa-cloud.com/) にアクセスして、テナントを作成します(まだ持っていない場合)。
</Step>
<Step>
**[Homebrew](https://brew.sh/) を使用して [Vespa CLI](/ja/clients/vespa-cli) をインストールします:**
```bash
$ brew install vespa-cli
```
	Windows を使用している、または Homebrew がない場合は、[Vespa CLI のページ](/ja/clients/vespa-cli)から直接ダウンロードしてください。
</Step>
<Step>
**Vespa クライアントを設定します:**
```bash
$ vespa config set target cloud
$ vespa config set application vespa-team.autotest
```
	"vespa-team" の代わりにステップ 1 のテナント名を使用してください。このガイドの他のステップでも同様に置き換えてください。
</Step>
<Step>
**Vespa Cloud のコントロール・プレーンへのアクセスを取得します:**
```bash
$ vespa auth login
```
	コマンドの指示に従って認証します。
</Step>
<Step>
**サンプル・[アプリケーション](/ja/basics/applications)をクローンします:**
```bash
$ vespa clone rag-blueprint myapp && cd myapp
```
クローンできる他のサンプル・アプリについては [sample-apps](https://github.com/vespa-engine/sample-apps) を参照してください。
</Step>
<Step>
**[データ・プレーン・アクセス](/ja/security/guide#data-plane)用の証明書をアプリケーションに追加します:**
```bash
$ vespa auth cert app
```
ここで書き込まれる `.pem` ファイルのパスを控えておくとよいでしょう。
</Step>
</Steps>


## アプリケーションのテスト


```bash
$ vespa deploy --wait 900 ./app
```


いくつかのドキュメントをフィードします。この処理ではチャンク化と埋め込みも行われるため、約 3 分かかります:


```bash
$ vespa feed dataset/docs.jsonl
```


これでクエリーを発行できます:


```bash
$ vespa query 'query=yc b2b sales'
```



```bash
$ vespa destroy --force
```

<Tip>
**ヒント:**

"-v" を追加すると、これがどのような HTTP リクエストになるかを確認できます。
</Tip>

おめでとうございます! これで、最先端の品質を提供しながら、数十億のドキュメントと毎秒数千のクエリーにスケールできる RAG アプリケーションが完成しました。
