## 適用範囲

Vespa プラットフォームはオープンソースであり、セルフマネージドのシステムにも Vespa Cloud サービス上にもデプロイできます。一部のアドオン(コア機能は含まれません)は、商用ライセンスの下でのみ利用可能です。

## 表記法

*イタリック*は次の用途に使用します:

- パス名、ファイル名、プログラム名、ホスト名、URL
- 定義される新しい用語

`等幅フォント`は次の用途に使用します:

- プログラミング言語の要素、コード例、キーワード、関数、クラス、インターフェース、メソッドなど
- コマンドおよびコマンドラインの出力

コマンドラインで実行するコマンドは、プロンプトを表す $ を先頭に付けて、次のように表示されます:

```bash
$ export PATH=$VESPA_HOME/bin:$PATH   # how to highlight text in pre
```
