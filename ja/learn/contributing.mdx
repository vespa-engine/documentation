## オープンな開発

Vespa のすべての作業は、[GitHub flow モデル](https://docs.github.com/en/get-started/quickstart/github-flow)を使用して、GitHub 上で直接行われます。master ブランチは週に数回リリースされており、ほぼ常に動作することが期待できます。[factory.vespa.ai で確認できるビルド](https://factory.vespa.ai)に加えて、大規模な受け入れテストとパフォーマンステストのスイートも継続的に実行されています。

### プルリクエスト

すべてのプルリクエストは、Vespa Committers チームのメンバーによってレビューされます。適切なレビュアーは、変更を行っている場所からソースツリーを上にたどった OWNERS ファイルで見つけることができます (OWNERS は、コードの一部の長期的な健全性を確保する特別な責任を負っています)。committer/OWNER になりたい場合は、質の高いコントリビューションを行うことがその第一歩です。

すべてのプルリクエストのチェックに合格することが必須です。

## バージョニング

Vespa はセマンティック・バージョニングを使用しています - [vespa versions](/ja/learn/releases) を参照してください。特に、package-info ファイルに @PublicAPI アノテーションを持つパッケージ内の Java API は、メジャーバージョン間で互換性のない変更を行うことができない点に注意してください。既存の型とメソッドシグネチャーは維持される必要があります (ただし deprecated としてマークすることは可能です)。

## Issue

Issue は [GitHub issues](https://github.com/vespa-engine/vespa/issues) で管理しています。自分で取り組むつもりがあるかどうかにかかわらず、機能リクエストやアイデアについても issue を提出してかまいません。

また、まだ誰も取り組んでいない大きな項目については [ToDo リスト](https://github.com/vespa-engine/vespa/blob/master/TODO.md)があります。

## コミュニティ

質問がある場合、経験を共有したい場合、または他の人を助けたい場合は、[Vespa Slack](https://slack.vespa.ai) のコミュニティに参加するか、[Stack Overflow](http://stackoverflow.com/questions/tagged/vespa) で Vespa をご覧ください。
