[エンベッダー](/ja/rag/embedding)のリファレンス設定です。

## モデル設定リファレンス

エンベッダーのモデルには [model](/ja/reference/applications/config-files#model) 型の設定を使用します。この設定は `model-id`、`url`、`path` の各属性を受け付けます。これらのうち複数を単一の設定値として指定でき、デプロイ環境に応じていずれか1つが使用されます:

- `model-id` が指定されており、アプリケーションが Vespa Cloud にデプロイされている場合は、`model-id` が使用されます。
- そうでない場合、`url` が指定されていれば、それが使用されます
- それ以外の場合は、`path` が使用されます。

`path` を使用する場合、モデルファイルはアプリケーション・パッケージ内で提供する必要があります。

## Huggingface エンベッダー

任意の [Huggingface トークナイザー](https://huggingface.co/docs/tokenizers/index)(多言語トークナイザーを含む)を使用してトークンを生成し、それを ONNX モデル形式で提供されたトランスフォーマーモデルへの入力とするエンベッダーです。

Huggingface エンベッダーは、[services.xml](/ja/reference/applications/services/services) の `container` タグ内で設定します:

```xml
<container id="default" version="1.0">
    <component id="hf-embedder" type="hugging-face-embedder">
        <transformer-model path="my-models/model.onnx"/>
        <tokenizer-model path="my-models/tokenizer.json"/>
        <prepend>
          <query>query:</query>
          <document>passage:</document>
        </prepend>
    </component>
    ...
</container>
```

### プライベートモデルハブ

[プライベートな Huggingface モデルハブ](https://huggingface.co/docs/hub/en/repositories-settings#private-repositories)でホストされているモデルを使用することもできます。

適切な権限を持つ API キーを Huggingface から取得し、[Vespa シークレットストア](/ja/security/secret-store)に追加します。シークレットをコンテナーの `<secrets>` に追加し、Huggingface モデルの設定でそれを参照します:

```xml
<container id="default" version="1.0">
  <secrets>
    <myPrivateHubApiKey vault="my-vault" name="my-secret-name" />
  </secrets>
  <component id="hf-embedder" type="hugging-face-embedder">
      <transformer-model url="my-url" secret-ref="myPrivateHubApiKey"/>
      <tokenizer-model url="my-url" secret-ref="myPrivateHubApiKey"/>
  </component>
</container>
```

## colbert エンベッダー

colbert エンベッダーは、[services.xml](/ja/reference/applications/services/services) の `container` タグ内で設定します:

```xml
<container version="1.0">
  <component id="colbert" type="colbert-embedder">
    <transformer-model path="models/colbertv2.onnx"/>
    <tokenizer-model url="https://huggingface.co/colbert-ir/colbertv2.0/raw/main/tokenizer.json"/>
    <max-query-tokens>32</max-query-tokens>
    <max-document-tokens>256</max-document-tokens>
  </component>
</container>
```

Vespa の colbert 実装は、WordPiece トークン化を使用するトランスフォーマーモデルのデフォルト設定で動作します。

## VoyageAI エンベッダー

[VoyageAI](https://www.voyageai.com/) API を使用して埋め込みを生成するエンベッダーです。

VoyageAI エンベッダーは、[services.xml](/ja/reference/applications/services/services) の `container` タグ内で設定します:

```xml
<container id="default" version="1.0">
    <component id="voyage" type="voyage-ai-embedder">
        <model>voyage-law-2</model>
        <api-key-secret-ref>voyage_api_key</api-key-secret-ref>
        <dimensions>1024</dimensions>
        <endpoint>https://api.voyageai.com/v1/embeddings</endpoint>
        <truncate>true</truncate>
        <batching max-size="16" max-delay="200ms"/>
    </component>
</container>
```

## SentencePiece エンベッダー

[SentencePiece](https://github.com/google/sentencepiece) のネイティブ Java 実装です。SentencePiece はスペースに依存せずにテキストをチャンクに分割するため、スペルミスに対して頑健であり、CJK 言語でも機能します。Huggingface モデルとのより良い互換性のためには、これよりも [Huggingface トークナイザー・エンベッダー](#huggingface-tokenizer-embedder)を優先してください。

これは[カスタムコンポーネント](/ja/applications/components)と組み合わせて使用するのに適しており、また生成されたテンソルを[ランキング](/ja/basics/ranking)で使用することもできます。

[SentencePiece エンベッダー](https://github.com/vespa-engine/vespa/blob/master/linguistics-components/src/main/java/com/yahoo/language/sentencepiece/SentencePieceEmbedder.java)を使用するには、[services.xml](/ja/reference/applications/services/services) に追加します:

```xml
<container version="1.0">
    <component id="mySentencePiece"
             class="com.yahoo.language.sentencepiece.SentencePieceEmbedder"
             bundle="linguistics-components">
      <config name="language.sentencepiece.sentence-piece">;
          <model>
              <item>
                <language>unknown</language>
                <path>model/en.wiki.bpe.vs10000.model</path>
              </item>
          </model>
        </config>
    </component>
  </container>
```

SentencePiece の設定で利用可能なオプションについては、[完全な設定定義](https://github.com/vespa-engine/vespa/blob/master/linguistics-components/src/main/resources/configdefinitions/language.sentencepiece.sentence-piece.def)を参照してください。

## Java からのエンベッダーの使用

class MyComponent {

## カスタムエンベッダー

Vespa は、テキストの埋め込みを提供できるコンポーネントを定義するための Java インターフェース [com.yahoo.language.process.Embedder](https://github.com/vespa-engine/vespa/blob/master/linguistics/src/main/java/com/yahoo/language/process/Embedder.java) を提供しています。

アプリケーションでカスタムエンベッダーを定義して Vespa から使用できるようにするには([クエリーテキストの埋め込み](/ja/rag/embedding#embedding-a-query-text)を参照)、このインターフェースを実装し、[コンポーネント](/ja/applications/developer-guide#developing-components)として [services.xml](/ja/reference/applications/services/container) に追加します:

```xml
<container version="1.0">
    <component id="myEmbedder"
      class="com.example.MyEmbedder"
      bundle="the name in artifactId in pom.xml">
        <config name='com.example.my-embedder'>
            <model model-id="minilm-l6-v2"/>
            <vocab path="files/vocab.txt"/>
            <myValue>foo</myValue>
        </config>
    </component>
</container>
```
