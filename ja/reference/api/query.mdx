APIの例については[クエリーAPIガイド](/ja/querying/query-api)を参照してください。

以下に挙げるすべてのリクエスト・パラメーターは、クエリー・プロファイルで設定できます。
最初の4つのプロパティ・ブロックは、
[クエリー・プロファイル・タイプ](/ja/querying/query-profiles#query-profile-types)としてもモデル化されています。
これらのタイプはクエリー・プロファイル(およびそれを継承するタイプ)から参照でき、
パラメーターの型チェックを提供します。

パラメーターには*完全名*があり、1つ以上の短いエイリアスを持つことがあります(以下では角括弧内に示します)。
どちらの名前もリクエストおよびクエリー・プロファイルで使用できます。
リクエストにおいて、エイリアスは大文字・小文字を区別しません。

Searcherコンポーネントからパラメーターにアクセスする場合、完全名はルートのQueryオブジェクトから
そのパラメーターまでのパスに対応します。

## HTTPステータス・コード

どのHTTPステータス・コードが返されるかは、以下のルールによって決まります:

- Resultにエラーが含まれていない場合(Result.hits().getError()==null): 200 OKが返されます。

- Resultにエラーが含まれ、通常のヒットが含まれていない場合:
    
      
        Result内のいずれかのErrorMessage
        (Result.hits().getErrorHit().errorIterator())のエラー・コードが「WEB SERVICE ERROR CODE」の場合、
        そのうちの最初のものが返されます。
      
      
        そうでない場合、「HTTP COMPATIBLE ERROR CODE」であれば、そのマッピングが返されます。
      
      
        それ以外の場合は500 INTERNAL_SERVER_ERRORが返されます。
