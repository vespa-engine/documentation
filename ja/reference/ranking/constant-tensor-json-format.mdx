このドキュメントでは、ファイルからテンソル定数を読み込む際に受け付けられる JSON フォーマットを例とともに説明します。利便性、コンパクトさ、読みやすさのために、テンソル型の詳細に応じて使用できるさまざまなフォーマットがあります:

- [密テンソル](#dense-tensors): インデックス付きディメンションのみ
- [疎テンソル](#sparse-tensors): マップ型ディメンションのみ
- [混合テンソル](#mixed-tensors): インデックス付きとマップ型の両方のディメンション

## 正規型

テンソル型はディメンションを任意の順序で宣言できますが、内部的には常にアルファベット順にソートされます。したがって、型「`tensor(category{}, brand{}, a[3], x[768], d0[1])`」の正規の文字列表現は「`tensor(a[3],brand{},category{},d0[1],x[768])`」であり、サイズ 768 の「x」ディメンションが最も内側になります。定数の場合、すべてのインデックス付きディメンションは既知のサイズを持つ必要があります。

## 密テンソル

インデックス付きディメンションのみを使用するテンソルは、ベクトルや行列などの格納に使用され、総称して「密（dense）」テンソルと呼ばれます。これらは、明確に定義された順序で既知の数のセルを常に持つため、特に扱いやすいものです。数値のネストされた配列として入力できます。サイズ 5 のベクトルの例:

```json
{
      "type": "tensor(x[5])",
      "values": [13.25, -22, 0.4242, 0, -17.0]
  }
```

「type」フィールドはオプションですが、存在する場合は[テンソル型の正規形](#canonical-type)と一致する必要があります。このフォーマットは、[ドキュメント JSON フォーマット](/ja/reference/schemas/document-json-format#tensor-short-form-indexed)の「インデックス付きテンソルの短縮形」に似ています。

3x4 行列の例。ディメンション名は、常に最も外側から最も内側へ[アルファベット順](#canonical-type)に処理されることに注意してください。

```json
{
      "type": "tensor(bar[3],foo[4])",
      "values": [
            [2.5, 1.0, 2.0, 3.0],
            [1.0, 2.0, 3.0, 2.0],
            [2.0, 3.0, 2.0, 1.5]
      ]
  }
```

配列は各ディメンションに対して宣言された数の要素を正確に持ち、正しくネストされている必要があることに注意してください。

この特定の入力では使用されない（サイズ 1 の）追加の「batch」ディメンションがあり、それでも追加の角括弧を必要とする ONNX モデル入力の例:

```json
{
      "type": "tensor(d0[1],d1[5],d2[2])",
      "values": [ [
          [1.1, 1.2],
          [2.1, 2.2],
          [3.1, 3.2],
          [4.1, 4.2],
          [5.1, 5.2]
      ] ]
  }
```

## 疎テンソル

マップ型ディメンションのみを使用するテンソルは、総称して「疎（sparse）」テンソルと呼ばれます。これらの JSON 入力では、セルを直接列挙します。マップ型ディメンションを 1 つだけ持つテンソルは、シンプルな JSON オブジェクトを入力として使用できます:

```json
{
      "type": "tensor(category{})",
      "cells": {
          "tag": 2.5,
          "another": 2.75
      }
  }
```

「type」フィールドはオプションです。このフォーマットは、[ドキュメント JSON フォーマット](/ja/reference/schemas/document-json-format#tensor-short-form-mapped)の「単一のマップ型ディメンションを持つテンソルの短縮形」に似ています。

複数のマップ型ディメンションを持つテンソルは、オブジェクトの配列を使用する必要があります。各オブジェクトは、すべてのディメンションのラベルを含む「address」と、セル値を持つ「value」を持ちます:

```json
{
      "type": "tensor(category{},product{})",
      "cells": [
          {
              "address": { "category": "foo", "product": "bar" },
              "value": 1.5
          },
          {
              "address": { "category": "qux", "product": "zap" },
              "value": 3.5
          },
          {
              "address": { "category": "pop", "product": "rip" },
              "value": 6.5
          }
      ]
  }
```

繰り返しになりますが、「type」フィールドはオプションですが、存在する場合は[テンソル型の正規形](#canonical-type)と一致する必要があります。

このフォーマットは[一般的な冗長形式](/ja/reference/schemas/document-json-format#tensor)としても知られており、あらゆるテンソル型に使用できます。

## 混合テンソル

マップ型とインデックス付きの両方のディメンションを持つテンソルは、「blocks」フォーマットを使用できます。これは疎テンソルの「cells」フォーマットに似ていますが、単一のセル値の代わりに、各アドレスに対して値のブロックを持ちます。1 つのマップ型ディメンションと 2 つのインデックス付きディメンションの場合:

```json
{
      "type": "tensor(a{},x[3],y[4])",
      "blocks": {
          "bar": [
              [1.0, 2.0, 0.0, 3.0],
              [2.0, 2.5, 2.0, 0.5],
              [3.0, 6.0, 9.0, 9.0]
          ],
          "foo": [
              [1.0, 0.0, 2.0, 3.0],
              [2.0, 2.5, 2.0, 0.5],
              [3.0, 3.0, 6.0, 9.0]
          ]
      }
  }
```

「type」フィールドはオプションですが、存在する場合は[テンソル型の正規形](#canonical-type)と一致する必要があります。このフォーマットは、[ドキュメント JSON フォーマット](/ja/reference/schemas/document-json-format#tensor-short-form-mixed)の「混合テンソルの短縮形」の最初のバリエーションに似ています。

2 つのマップ型ディメンションと 1 つのインデックス付きディメンションの場合:

```json
{
      "type": "tensor(a{},b{},x[3])",
      "blocks": [
          {
              "address": { "a": "qux", "b": "zap" },
              "values": [2.5, 3.5, 4.5]
          },
          {
              "address": { "a": "foo", "b": "bar" },
              "values": [1.5, 2.5, 3.5]
          },
          {
              "address": { "a": "pop", "b": "rip" },
              "values": [3.5, 4.5, 5.5]
          }
      ]
  }
```

繰り返しになりますが、「type」フィールドはオプションです。このフォーマットは、[ドキュメント JSON フォーマット](/ja/reference/schemas/document-json-format#tensor-short-form-mixed)の「混合テンソルの短縮形」の 2 番目のバリエーションに似ています。
