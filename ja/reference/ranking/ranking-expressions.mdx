title: "ランキング式"
---


これは、アプリケーション固有のランキング関数を構成するために使用される_ランキング式_の完全なリファレンスです。ランキング式の使い方の例と概要については、[ランキングの概要](/ja/basics/ranking)を参照してください。

ランキング式は、通常の関数表記に似たシンプルな言語で記述します。ランキング式のアトムは_ランク・フィーチャー_と_定数_です。これらのアトムは、スカラーとテンソルに対する_算術演算_やその他の_組み込み関数_によって組み合わせることができます。

  <tbody>
    <tr>
      <td>ランク・フィーチャー</td>
      <td>ランク・フィーチャーは、クエリー/ドキュメントの組み合わせごとに Vespa が計算または参照する名前付きの値です。ランキング式で利用可能なすべてのランク・フィーチャーの一覧については、<a href="/ja/reference/ranking/rank-features" aria-label="ランク・フィーチャーのリファレンス">ランク・フィーチャーのリファレンス</a>を参照してください。</td>
    </tr>
    <tr>
      <td>定数</td>
      <td>定数は、浮動小数点数、ブーリアン(true/false)、または引用符で囲まれた文字列のいずれかです。ランキング式はスカラーとテンソルしか扱えないため、文字列とブーリアンは直ちにスカラーに変換されます - true は 1.0 に、false は 0.0 に、文字列はそのハッシュ値になります。つまり、&#42;&#42;文字列は等価比較にしか使えず&#42;&#42;、テンソルからスライスするキーをパラメーター化するといった他の用途には正しく動作しません。</td>
    </tr>
  </tbody>
</table>

## 算術演算

基本的な数学演算は中置記法で表現します:

```bash
a + b * c
```

算術演算はスカラーに加えて任意のテンソルに対しても機能し、セルの結合にその算術演算を使ってテンソルを join する短縮形です。例えば `tensorA * tensorB` は `join(tensorA, tensorB, f(a,b)(a * b))` と同じです。

## if 関数

`if` 関数は、条件の真偽値に基づいて 2 つのサブ式のいずれかを選択します。

```bash
if (expression1operatorexpression2, trueExpression, falseExpression)
```

最初の引数で与えられた条件が真であれば引数 2 の式が使用され、そうでなければ引数 3 が使用されます。4 つの式には任意のランキング式を指定できます。ランキング式の if 関数で使用できる条件演算子:

メンバーシップ演算子 `in` は、少し変形した if 構文を使用します:

```bash
if (expression1in[expression2, expression3, ..., expressionN], trueExpression, falseExpression)
```

expression1 が expression2 から expressionN のいずれかと等しい場合は trueExpression が使用され、そうでない場合は falseExpression が使用されます。

## switch 関数

<Info>
  **注:** Vespa 8.626.55 から利用可能
</Info>

`switch` 関数は、値のマッチングに基づいて複数のサブ式から選択します。複数の選択肢から選ぶ場合に、`if` 文の連鎖よりも読みやすい代替手段を提供します。

```bash
switch (discriminant) {
    case value1: result1,
    case value2: result2,
    ...
    default: defaultResult
}
```

`discriminant` 式は、各 `case` の値の式と順番に等価比較されます。マッチが見つかると、対応する結果の式が評価されて返されます。どの case にもマッチしない場合は、`default` の結果が返されます。すべての式には任意のランキング式を指定できます。少なくとも 1 つの `case` を指定する必要があります。`default` は必須です。

## foreach 関数

foreach 関数は厳密には式言語の一部ではなく、[ランク・フィーチャー](/ja/reference/ranking/rank-features#foreachdimensionvariablefeatureconditionoperation)として実装されています。

### プリミティブ関数におけるラムダ関数

一部のプリミティブ関数は、テンソルのセルの集合に対して評価・適用されるラムダ関数を受け取ります。この関数は単一の式で構成され、その形式と組み込み関数は[一般的なランキング式](/ja/reference/ranking/ranking-expressions)と同じです。ただし、アトムはラムダの引数リストで定義された引数になります。

式はラムダの外側の変数やデータ構造にアクセスできません。つまり、これらはクロージャーではありません。

例:

```bash
f(x)(log(x))
f(x,y)(if(x < y, 0, 1))
```

### 非プリミティブ関数
