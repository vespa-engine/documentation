---
title: "hosts.xml"
---


*hosts.xml* は、[アプリケーション・パッケージ](/ja/reference/applications/application-packages)内の設定ファイルです。要素:

hosts
    [host \[name\]](#host)
        [alias](#alias)

*hosts.xml* の目的は、実際のホスト名に対して自分で定義したエイリアスを追加することです。エイリアスは [services.xml](/ja/reference/applications/services/services) で、サービスインスタンスをホストにマッピングするために使用されます。複数のホストにデプロイする場合にのみ必要です。

## host

サブ要素:

- [`alias`](#alias)

例:

```xml
<hosts>
    <host name="myserver0.mydomain.com">
        <alias>SEARCH0</alias>
        <alias>CONTAINER0</alias>
    </host>
    <host name="myserver1.mydomain.com">
        <alias>SEARCH1</alias>
        <alias>CONTAINER1</alias>
    </host>
</hosts>
```

## alias

[services.xml](/ja/reference/applications/services/services) でホストを参照するために使用されるエイリアス。
