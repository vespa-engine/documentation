これは、JUnit 5 のユニット・テストとして Java で書かれた [Vespa アプリケーションのシステム・テスト](/ja/applications/testing)に関する Vespa テスティングのリファレンスです。

これらのテストは、HTTP インターフェースを使用して Vespa アプリケーションの動作を検証します。Java を使わずにテストを書く場合は、[基本 HTTP テスト・リファレンス](/ja/reference/applications/testing)を参照してください。

テストの実行方法の例は[テスティング・ガイド](/ja/applications/testing)を参照してください。

## テスト・スイート

[テスティングのドキュメント](/ja/applications/testing)では、4 つのテスト・コード・カテゴリーで構成される 3 つのテスト・シナリオが定義されています。[com.yahoo.vespa:tenant-cd-api](https://search.maven.org/artifact/com.yahoo.vespa/tenant-cd-api) の*システム・テスト・フレームワーク*は、JUnit テスト・クラスがどのカテゴリーに属するかを宣言するために Java アノテーションを使用します。特定のカテゴリーに属するテストを Maven で実行するには、JUnit 5 のテスト・*タグ*を指定する必要があります:

```sh
$ mvn test -D test.categories=system -D vespa.test.config=/path-to/test-config.json
```

## TestNG

Vespa の JUnit 5 テスト・スイートを TestNG のユニット・テストと組み合わせることは可能です。両方のフレームワークの統合を有効にするには、Maven の surefire プラグインを明示的に設定する必要があります。Vespa のテスト・スイートを実行するには `-D test.categories=[tag]` を指定します。ここで *\[tag\]* は、[テスト・スイート](#test-suites)に記載されている値のいずれかです。

```xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-surefire-plugin</artifactId>
    <dependencies>
        <dependency>
            <groupId>org.apache.maven.surefire</groupId>
            <artifactId>surefire-junit-platform</artifactId>
            <version>${surefire.vespa.tenant.version}</version>
        </dependency>
        <dependency>
            <groupId>org.apache.maven.surefire</groupId>
            <artifactId>surefire-testng</artifactId>
            <version>${surefire.vespa.tenant.version}</version>
        </dependency>
    </dependencies>
</plugin>
```
