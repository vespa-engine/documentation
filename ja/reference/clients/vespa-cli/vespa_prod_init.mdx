### Synopsis

本番デプロイ用に service.xml と deployment.xml を変更します。

このコマンドで利用できるのは基本的なデプロイ設定のみです。高度な設定については、関連する Vespa Cloud のドキュメントを参照し、deployment.xml と services.xml を直接変更してください。

リファレンス:
[/ja/reference/applications/services/services](/ja/reference/applications/services/services)
[/ja/reference/applications/deployment](/ja/reference/applications/deployment)

```bash
vespa prod init [flags]
```
