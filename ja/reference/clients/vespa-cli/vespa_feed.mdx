### 概要

複数のドキュメント操作を Vespa にフィードします。

このコマンドは、大量のドキュメントを Vespa クラスターに効率的にフィードするために使用できます。

json-file の内容は、JSON 配列、または改行で区切られた JSON オブジェクト（JSONL）のいずれかである必要があります。

json-file が単一のダッシュ（'-'）の場合、ドキュメントは標準入力から読み込まれます。

フィードが完了すると、フィード・セッションのメトリクスが JSON 形式で標準出力に出力されます:

- feeder.operation.count: ユーザーからフィーダーに渡された操作の数。リトライは含まれません。
- feeder.seconds: フィードに費やされた合計時間。
- feeder.ok.count: 成功した操作の数。
- feeder.ok.rate: 1 秒あたりの成功した操作の数。
- feeder.error.count: ネットワークエラー（トランスポート層）の数。
- feeder.inflight.count: 現在送信中の操作の数。
- http.request.count: リトライを含む、実行された HTTP リクエストの数。
- http.request.bytes: 送信されたバイト数。
- http.request.MBps: MB/s で測定されたリクエストのスループット。これは生の操作スループットであり、ネットワークのスループットではありません。つまり、圧縮を使用してもこの数値には影響しません。
- http.exception.count: feeder.error.count と同じ。vespa-feed-client との互換性のために存在します。
- http.response.count: 受信した HTTP レスポンスの数。
- http.response.bytes: 受信したバイト数。
- http.response.MBps: MB/s で測定されたレスポンスのスループット。
- http.response.error.count: 受信した OK 以外の HTTP レスポンスの数。
- http.response.latency.millis.min: 成功した操作の最小レイテンシー。
- http.response.latency.millis.avg: 成功した操作の平均レイテンシー。
- http.response.latency.millis.max: 成功した操作の最大レイテンシー。
- http.response.code.counts: HTTP コードごとにグループ化されたレスポンスの数。


```bash
vespa feed json-file [json-file]... [flags]
```

### 例

```bash
$ vespa feed docs.jsonl moredocs.json
$ cat docs.jsonl | vespa feed -
```

### オプション

```bash
      --compression string       Whether to compress the document data when sending the HTTP request. Default is "auto", which compresses large documents. Must be "auto", "gzip" or "none" (default "auto")
      --connections int          The number of connections to use (default 8)
      --deadline int             Exit if this number of seconds elapse without any successful operations. 0 to disable (default 0)
      --header strings           Add a header to all HTTP requests, on the format 'Header: Value'. This can be specified multiple times
  -h, --help                     help for feed
      --inflight int             The target number of inflight requests. 0 to dynamically detect the best value (default 0)
      --progress int             Print stats summary at given interval, in seconds. 0 to disable (default 0)
      --route string             Target Vespa route for feed operations (default "default")
      --speedtest int            Perform a network speed test using given payload, in bytes. 0 to disable (default 0)
      --speedtest-duration int   Duration of speedtest, in seconds (default 60)
      --timeout int              Individual feed operation timeout in seconds. 0 to disable (default 0)
      --trace int                Network traffic trace level in the range [0,9]. 0 to disable (default 0)
      --verbose                  Verbose mode. Print successful operations in addition to errors
  -w, --wait int                 Number of seconds to wait for service(s) to become ready. 0 to disable (default 0)
```

### 親コマンドから継承されるオプション

```bash
  -a, --application string   The application to use. Format "tenant.application.instance" - instance is optional (tenant required for cloud targets)
  -C, --cluster string       The container cluster to use. This is only required for applications with multiple clusters
  -c, --color string         Whether to use colors in output. Must be "auto", "never", or "always" (default "auto")
  -i, --instance string      The instance of the application to use
  -q, --quiet                Print only errors
  -t, --target string        The target platform to use. Must be "local", "cloud", "hosted" or an URL (default "local")
  -z, --zone string          The zone to use. This defaults to a dev zone (cloud only)
```
