### 概要

Vespa Cloud データ・プレーンでの認証用に、新しい自己署名証明書を作成します。

秘密鍵と証明書は Vespa CLI のホーム・ディレクトリーに保存されます('vespa help config' を参照)。その後、他のコマンドは必要に応じて証明書を自動的に読み込みます。証明書は、このコマンドの引数として指定されたアプリケーション・パッケージ(デフォルトは '.')に追加されます。

環境変数によって、使用する秘密鍵と証明書をオーバーライドすることが可能です。これは継続的インテグレーション・システムで便利です。

また、CA 証明書をオーバーライドすることも可能で、これはセルフホストの Vespa サービスで自己署名証明書を使用する場合に便利です。詳細は [/ja/security/mtls.html](/ja/security/mtls) を参照してください。

CA 証明書、証明書、鍵をインラインで設定する例:

    export VESPA_CLI_DATA_PLANE_CA_CERT="my CA cert"
    export VESPA_CLI_DATA_PLANE_CERT="my cert"
    export VESPA_CLI_DATA_PLANE_KEY="my private key"

CA 証明書、証明書、鍵をカスタム・パスから読み込む例:

    export VESPA_CLI_DATA_PLANE_CA_CERT_FILE=/path/to/cacert
    export VESPA_CLI_DATA_PLANE_CERT_FILE=/path/to/cert
    export VESPA_CLI_DATA_PLANE_KEY_FILE=/path/to/key

サーバーの証明書チェーンとホスト名の検証を無効化する例:

    export VESPA_CLI_DATA_PLANE_TRUST_ALL=true

環境変数で鍵ペアをオーバーライドした場合、その鍵ペアが常にすべてのアプリケーションで使用されることに注意してください。アプリケーション固有の鍵を指定することはできません。

詳細は [/ja/security/guide.html](/ja/security/guide) を参照してください。

```bash
vespa auth cert [flags]
```

### 例

```bash
$ vespa auth cert
$ vespa auth cert -a my-tenant.my-app.my-instance
$ vespa auth cert -a my-tenant.my-app.my-instance path/to/application/package
```

### オプション

```bash
  -f, --force       Force changes without prompting (overwrite when creating, prune when pruning)
  -h, --help        help for cert
      --new-key     Appends a new certificate if certificate already exists. Useful for rotating credentials
  -N, --no-add      Do not add certificate to the application package
      --prune-old   Remove all but the newest certificate from the certificate file. Useful after completing credential rotation
```

### 親コマンドから継承されるオプション

```bash
  -a, --application string   The application to use. Format "tenant.application.instance" - instance is optional (tenant required for cloud targets)
  -C, --cluster string       The container cluster to use. This is only required for applications with multiple clusters
  -c, --color string         Whether to use colors in output. Must be "auto", "never", or "always" (default "auto")
  -i, --instance string      The instance of the application to use
  -q, --quiet                Print only errors
  -t, --target string        The target platform to use. Must be "local", "cloud", "hosted" or an URL (default "local")
  -z, --zone string          The zone to use. This defaults to a dev zone (cloud only)
```
