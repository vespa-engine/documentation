### Synopsis

グローバルフラグの永続的な値を管理します。

このコマンドを使うと、Vespa CLI にあるグローバルフラグに永続的な値を設定できます。以降の実行では、フラグは設定ファイルから読み込まれるため、省略できるようになります。

設定はデフォルトで $HOME/.vespa に書き込まれます。このパスは、VESPA_CLI_HOME 環境変数を設定することで上書きできます。

オプションをローカルに設定する場合、設定は作業ディレクトリの .vespa に書き込まれます。設定を読み込む際、Vespa CLI はカレントディレクトリと親ディレクトリから .vespa を検索するため、アプリケーションのサブディレクトリからコマンドを実行できます。これにより、アプリケーションごとに個別の設定オプションを持つことができます。

Vespa CLI は、指定されたオプションの値を、優先度の高い順に次の順序で選択します:

1. コマンドラインで指定されたフラグの値
2. ローカル設定の値
3. グローバル設定の値
4. デフォルト値

以下のグローバルフラグ／オプションを設定できます:

application

管理対象のアプリケーション ID を指定します。ドットで区切られた 3 つの部分で構成され、3 番目の部分は省略可能です。3 番目の部分を省略した場合、デフォルトは "default" になります。これは "cloud" および "hostedターゲットにのみ関係します。詳細は [/ja/learn/tenant-apps-instances.html](/ja/learn/tenant-apps-instances) を参照してください。デフォルト値はありません。例: tenant1.app1、tenant1.app1.instance1

cluster

管理対象のコンテナー・クラスターを指定します。空のまま（デフォルト）にした場合、アプリケーションにコンテナー・クラスターが 1 つしかなければ、そのクラスターが自動的に選択されます。アプリケーションに複数のクラスターがある場合は、services.xml で指定された有効なクラスター名を指定する必要があります。詳細は [/ja/reference/applications/services/container.html](/ja/reference/applications/services/container) を参照してください。

color

Vespa CLI が色をどのように使うかを制御します。"auto"（デフォルト）に設定するとターミナルがサポートしている場合に色が有効になり、"never" は色を完全に無効にし、"always" は常に色を有効にします。

instance

管理対象のアプリケーションのインスタンスを指定します。指定した場合、'application' オプションの一部として指定されたインスタンスよりも優先されます。デフォルト値はなく、"cloud" および "hosted" ターゲットにのみ関係します。例: instance2

quiet

情報出力を抑制します。エラーは引き続き表示されます。

target

Vespa プラットフォームと連携するコマンド（例: vespa deploy や vespa query）で使用するターゲットを指定します。指定可能な値は次のとおりです:

- local:  （デフォルト）localhost で稼働している Vespa プラットフォームに接続します。このターゲットを使用する場合、コンテナー・クラスターは自動的に検出され、cluster オプションで選択されます。これは、configserver がポート 19071（Vespa コンテナーイメージ使用時のデフォルト）で利用可能であることを前提としています。
- cloud:  Vespa Cloud に接続します。このターゲットを使用する場合、コンテナー・クラスターは自動的に検出され、cluster オプションで選択できます。
- hosted: ホスティングされた Vespa に接続します（内部利用向けに予約）
- *url*:  指定された URL で稼働しているプラットフォームに接続します。これは、実行中のコマンドに具体的な URL をターゲットにするよう指示します。cluster オプションはこのターゲットと併用できません。

cloud および hosted ターゲットでは、認証は自動的に設定されます。例えば mTLS で構成されたセルフホストの Vespa インストール向けにカスタムの秘密鍵と証明書を設定するには、'vespa auth cert' のドキュメントを参照してください。

zone

Vespa Cloud アプリケーションへの接続時に使用するカスタム zone を指定します。これは cloud および hosted ターゲットにのみ関係し、デフォルトは dev zone です。利用可能な zone については [/ja/operations/zones.html](/ja/operations/zones) を参照してください。例: dev.aws-us-east-1c、dev.gcp-us-central1-f

```bash
vespa config [flags]
```
