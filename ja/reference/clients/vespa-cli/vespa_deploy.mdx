### 概要

アプリケーション・パッケージをデプロイ(prepare と activate)します。

アプリケーション・パッケージは、デプロイ可能な Vespa アプリケーションを定義します。このパッケージに含まれるファイルの詳細は [/ja/reference/applications/application-packages.html](/ja/reference/applications/application-packages) を参照してください。

はじめるには、'vespa clone' を使用してサンプル・アプリケーションをダウンロードできます。

このコマンドはアプリケーション・パッケージをデプロイします。deploy が正常に完了すると、アプリケーション・パッケージはコンフィグ・サーバー上で検証され、activate されています。個々のノードへの適用プロセスは開始されていますが、完了していない場合があります。

アプリケーション・ディレクトリーを指定しない場合、デフォルトは作業ディレクトリーです。

Vespa Cloud では、デプロイメントで使用する Vespa ランタイムのバージョン(--version)をオーバーライドできます。このオプションは、特定のバージョンを使用する理由がある場合にのみ使用してください。デフォルトでは、Vespa Cloud が適切なバージョンを選択します。


```bash
vespa deploy [application-directory-or-file] [flags]
```

### 例

```bash
$ vespa deploy .
$ vespa deploy -t cloud
$ vespa deploy -t cloud -z dev.aws-us-east-1c  # -z can be omitted here as this zone is the default
$ vespa deploy -t cloud -z dev.gcp-us-central1-f
```

### オプション

```bash
  -A, --add-cert           Copy certificate of the configured application to the current application package
  -h, --help               help for deploy
  -l, --log-level string   Log level for Vespa logs. Must be "error", "warning", "info" or "debug" (default "error")
  -V, --version string     Override the Vespa runtime version to use in Vespa Cloud
  -w, --wait int           Number of seconds to wait for service(s) to become ready. 0 to disable (default 0)
```

### 親コマンドから継承されるオプション

```bash
  -a, --application string   The application to use. Format "tenant.application.instance" - instance is optional (tenant required for cloud targets)
  -C, --cluster string       The container cluster to use. This is only required for applications with multiple clusters
  -c, --color string         Whether to use colors in output. Must be "auto", "never", or "always" (default "auto")
  -i, --instance string      The instance of the application to use
  -q, --quiet                Print only errors
  -t, --target string        The target platform to use. Must be "local", "cloud", "hosted" or an URL (default "local")
  -z, --zone string          The zone to use. This defaults to a dev zone (cloud only)
```
