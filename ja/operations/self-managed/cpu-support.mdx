---
title: "CPU サポート"
---

最大限のパフォーマンスを実現するため、現在のバージョンの x86\_64 用 Vespa は [Haswell (2013)](https://en.wikipedia.org/wiki/Haswell_\(microarchitecture\)) 以降の CPU 専用にコンパイルされています。それより古い CPU で実行しようとすると、次のようなエラーメッセージが表示される可能性があります:

```bash
Problem running program /opt/vespa/bin/vespa-runserver => died with signal: illegal instruction (you probably have an older CPU than required)
```

または、古いバージョンの Vespa では次のようなメッセージが表示されます

```bash
/usr/local/bin/start-container.sh: line 67: 10 Illegal instruction /opt/vespa/bin/vespa-start-configserver
```

古い CPU で Vespa を実行したい場合は、[汎用 x86 コンテナーイメージ](https://hub.docker.com/r/vespaengine/vespa-generic-intel-x86_64/)を提供しています。このイメージは通常のイメージより低速で、テストの頻度も少なく、更新頻度も低くなっています。

**このイメージを使用して Vespa の Docker コンテナーを起動するには:**

```bash
$ docker run --detach --name vespa --hostname vespa-container \
  --publish 8080:8080 --publish 19071:19071 \
  vespaengine/vespa-generic-intel-x86_64
```
