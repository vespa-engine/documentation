<Danger>
**警告:** 

ログアーカイブバケットの構造は予告なく変更される場合があります
</Danger>

Terraform を使用してお使いのクラウドプロバイダーアカウントに Vespa Cloud Enclave を構築すると、モジュールは enclave に設定した Vespa Cloud ゾーンごとにストレージバケットを作成します。これらのストレージバケットは、お使いのアカウント内で Vespa を実行しているマシンからのログをアーカイブするために使用されます。

バケットはお客様自身のクラウドアカウント内にあるため、IAM ロールを登録したり、Vespa Cloud Console でアクセスを設定したりする必要はありません — 既存のクラウド認証情報を使用してアーカイブバケットに直接アクセスできます。

<Frame>
![Enclave アーカイブビュー](/assets/img/archive-aws-enclave.png)
</Frame>

enclave に設定された Vespa Cloud ゾーンごとに 1 つのストレージバケットが作成されます。バケットの名前は、enclave をセットアップするクラウドプロバイダーによって異なります。

ファイルは、ロギングシステムによってファイルがローテーションされたとき、または仮想マシンがアプリケーションからデプロビジョニングされたときに、アーカイブバケットに同期されます。その結果、アップロードの頻度は Vespa アプリケーションのアクティビティに依存します。

## ディレクトリ構造

バケット内のディレクトリ構造は次のとおりです。

```bash
<tenant>/<application>/<instance>/<host>/logs/<logtype>/<logfile>
```

- `tenant` はテナント ID です。
- `application` はログを生成したアプリケーション ID です。
- `instance` は生成されたログのインスタンス ID です (例: `default`)。
- `host` はログを生成したホストの名前のプレフィックスです (例: `e103a`)。
- `logtype` はディレクトリ内のログの種類です (下記参照)。
- `logfile` はログの個々のファイルです。

## ログの種類

このバケットに同期されるログには 3 つの種類があります。

- `vespa`: [Vespa ログ](/ja/reference/operations/log-files)
- `access`: [アクセスログ](/ja/operations/access-logging)
- `connection`: [コネクションログ](/ja/operations/access-logging#connection-log)
