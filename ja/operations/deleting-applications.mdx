<Warning>
**警告:** 

以下の手順を実行すると、プロダクションのインスタンスまたはリージョンと、その中のすべてのデータが削除されます。データは復旧できません。
</Warning>


## アプリケーションの削除

アプリケーションを削除するには、コンソールを使用します:

- https://console.vespa-cloud.com/tenant/tenant-name/application の *application* ビューに移動します。右端に `ACTION` としてゴミ箱アイコンがあります。
- *https://console.vespa-cloud.com/tenant/tenant-name/application/app-name/prod/deploy* の *deploy* ビューに移動します。

<Frame>
![プロダクションのデプロイメントを削除する](/assets/img/console/delete-production-deployment.png)
</Frame>

アプリケーションのデプロイメントが削除されたら、[コンソール](https://console.vespa-cloud.com)でアプリケーションを削除します。アプリケーション・パッケージをビルドしてデプロイする CI ジョブがあれば、それも削除します。

## インスタンス / リージョンの削除

アプリケーションからインスタンス、またはリージョンへのデプロイメントを削除するには:

<Steps>
<Step>
[deployment.xml](/ja/reference/applications/deployment#instance) で、`prod` から `region` を削除するか、`deployment` から `instance` を削除します:
```xml
<deployment version="1.0">
     <prod>
         <region>aws-us-east-1c</region>
         <!-- Removing the deployment in the region 'aws-eu-west-1a' -->
         <!--region>aws-eu-west-1a</region-->
     </prod>
 </deployment>
```
</Step>
<Step>
[validation-overrides.xml](/ja/reference/applications/validation-overrides) を追加または変更し、Vespa Cloud がプロダクションのインスタンスを削除できるようにします:
	
```xml
<validation-overrides>
    <allow until="2021-03-01" comment="Remove region/instance ...">deployment-removal</allow>
    <!-- If the region was part of a global endpoint/instance had a global endpoint: -->
    <allow until="2021-03-01" comment="Remove region/instance ...">global-endpoint-change</allow>
</validation-overrides>
```
</Step>
<Step>
アプリケーション・パッケージをビルドしてデプロイします。
</Step>
</Steps>
