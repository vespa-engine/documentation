---
title: "権限"
---

Vespa Operator は、名前空間内で次の権限を必要とします。これらの権限は、リソースごとに Kubernetes の [API verbs](https://kubernetes.io/docs/reference/access-authn-authz/rbac/) で列挙されています。

<table className="vespa-table">
  <thead>
    <tr>
      <th>Kubernetes リソース</th>
      <th>必要な権限</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>CustomResourceDefinitions</td>
      <td>create, get, list, watch</td>
    </tr>
    <tr>
      <td>VespaSet</td>
      <td>get, list, watch, create, update, patch, delete</td>
    </tr>
    <tr>
      <td>VespaSet Subresources</td>
      <td><code>{`vespasets/status`}</code>: update, patch   <code>{`vespasets/finalizers`}</code>: update</td>
    </tr>
    <tr>
      <td>ConfigMaps</td>
      <td>get, list, watch, create, update, patch, delete</td>
    </tr>
    <tr>
      <td>Services</td>
      <td>get, list, watch, create, update, patch, delete</td>
    </tr>
    <tr>
      <td>Pods</td>
      <td>get, list, watch, create, update, patch, delete</td>
    </tr>
    <tr>
      <td>Pod Execution</td>
      <td>get, create</td>
    </tr>
    <tr>
      <td>Events</td>
      <td>create, patch</td>
    </tr>
    <tr>
      <td>PersistentVolumeClaims</td>
      <td>get, list, watch, create, update, patch, delete</td>
    </tr>
    <tr>
      <td>ServiceAccounts</td>
      <td>get, list, watch, create, update, patch, delete</td>
    </tr>
    <tr>
      <td>Roles</td>
      <td>get, list, watch, create, update, patch, delete</td>
    </tr>
    <tr>
      <td>RoleBindings</td>
      <td>get, list, watch, create, update, patch, delete</td>
    </tr>
  </tbody>
</table>
