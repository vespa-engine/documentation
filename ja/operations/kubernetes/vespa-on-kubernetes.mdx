Vespa アプリケーションは、Vespa Operator を通じて Kubernetes 上にデプロイおよび管理できます。Vespa Operator は、Vespa のインフラストラクチャーとアプリケーションの管理に、Kubernetes ネイティブなエクスペリエンスを提供します。

## 概要

Vespa Operator は、次の機能を提供することで Kubernetes 上での Vespa の運用を簡素化します。

- [Custom Resource Definition (CRD)](https://kubernetes.io/docs/concepts/extend-kubernetes/api-extension/custom-resources/) による宣言的な設定
- Vespa インフラストラクチャーの自動デプロイと管理
- Vespa アプリケーションの自動デプロイ、更新、アップグレード
- 障害処理などの重要なライフサイクル運用
- TLS によるクラスターのセキュリティー確保
- Vespa アプリケーションの Kubernetes ネイティブなモニタリング
- Kubernetes ネイティブなツールとの統合
