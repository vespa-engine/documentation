These pages cover configuring a Vespa on Kubernetes deployment.

  • Configure Local Storage Type — provision node-local storage for content clusters to maximize performance.
  • Configure Log Collections — collect and forward Vespa logs with Fluent Bit and Loki.
  • Configure External Access Layer — expose Vespa endpoints outside the Kubernetes cluster.
  • Configure Custom Overrides — customize Vespa pods with PodTemplateSpec overlays.
  • Configure TLS Encryption with CertManager — enable mTLS for internal communication and TLS for ingress traffic.
  • Configure Monitoring — collect metrics with the Prometheus Operator and forward them to Grafana Cloud.
