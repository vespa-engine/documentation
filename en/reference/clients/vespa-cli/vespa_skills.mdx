## vespa skills

Manage Vespa AI-assistant skills

### Synopsis

Manage Vespa AI-assistant skills.

Skills teach AI coding assistants how to work with Vespa: schema authoring, application packages, queries, feeding and more. Skills are downloaded from https://github.com/vespa-engine/skills and installed for one or more agent harnesses: Claude Code, Codex, Cursor and Antigravity CLI.

```txt
vespa skills [flags]
```
