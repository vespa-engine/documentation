---
title: "vespa version"
description: "Usage of vespa version, which prints the installed Vespa CLI version and checks for a newer release unless --no-check is set."
---

```bash
vespa version [flags]
```

### Options

```text
  -h, --help       help for version
  -n, --no-check   Do not check if a new version is available
```
