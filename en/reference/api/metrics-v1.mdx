The _node metrics API_ is available on each _node_ at the metrics proxy port, default _http://host:19092/metrics/v1/values_.

Refer to [monitoring](/en/operations/self-managed/monitoring) for an overview of nodes, services and metrics APIs for self-hosted applications.
