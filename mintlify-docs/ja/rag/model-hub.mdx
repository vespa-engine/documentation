Vespa Cloud は、アプリケーションで使用できる一連の機械学習モデルを提供しています。これらのモデルは Vespa Cloud で常に利用可能であり、[フローズンモデル](https://blog.vespa.ai/tailoring-frozen-embeddings-with-vespa/)です。また、Vespa のアプリケーション・パッケージにデプロイすることで、独自の埋め込みモデルを持ち込むこともできます。

Vespa Cloud が提供するモデルを使用するには、モデル設定を指定する箇所で `model-id` 属性を設定します。例えば、Vespa が提供する [Huggingface embedder](/ja/rag/embedding#huggingface-embedder) を設定する場合、次のように書けます:

```xml
<container id="default" version="1.0">
    <component id="e5" type="hugging-face-embedder">
        <transformer-model model-id="e5-small-v2"/>
    </component>
    ...
</container>
```

これにより、アプリケーションはクエリーとドキュメントの両方に対する[テキスト埋め込み](/ja/rag/embedding#embedding-a-query-text)推論をサポートするようになります。GPU アクセラレーション付きでプロビジョニングされたノードは、埋め込み推論に自動的に GPU を使用します。

## Vespa Cloud の埋め込みモデル

Vespa モデルハブ上のモデルは、優れたパフォーマンスを持つ選りすぐりのオープンソース埋め込みモデルです。パフォーマンスと品質の詳細については、[埋め込みのトレードオフに関する Vespa ブログ](https://blog.vespa.ai/embedding-tradeoffs-quantified/)を参照してください。これらの埋め込みモデルは、検索(セマンティック検索)、リランキング、クラスタリング、分類などに役立ちます。

### Huggingface Embedder

これらのモデルは Huggingface Embedder `type="hugging-face-embedder"` で利用できます。これらのモデルはすべて、`string` または `array<string>` からテンソル表現へのマッピングをサポートしています。

出力テンソルの [cell-precision](/ja/performance/feature-tuning#cell-value-types) は `<float>`、`<bfloat16>`、または `<int8>` を指定できます。

ほとんどのモデルは[バイナリ化](/ja/rag/binarizing-vectors)もサポートしており、その場合は [distance-metric](/ja/reference/schemas/schemas#distance-metric) に `angular` の代わりに `hamming` を使用する必要があります。E5 および multilingual-e5 モデルはバイナリ化をサポートしていません。品質への影響の詳細については、[nanobeir hybrid evaluation leaderboard](https://huggingface.co/spaces/vespa-engine/nanobeir-hybrid-evaluation) を参照してください。

## セルフホストと Vespa Cloud の両方で動作するアプリケーションの作成

`model-id`(Vespa Cloud で使用されます)と url/path(セルフホストのデプロイで使用されます)の両方を指定することもできます:

```bash
<transformer-model model-id="minilm-l6-v2" path="myAppPackageModels/myModel.onnx"/>
```

これは、例えば本番環境では Vespa Cloud のモデルを使用し、セルフホストの開発環境では縮小版またはダミーのモデルを使用するアプリケーション・パッケージを作成する場合に便利です。

## 任意の設定での Vespa Cloud モデルの使用

model-id の指定は、その設定が Vespa 由来のものか自分で定義したものかにかかわらず、[`model` 型の任意の設定フィールド](/ja/applications/configuring-components#adding-files-to-the-component-configuration)に対して行えます。
