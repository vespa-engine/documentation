---
title: "Vespa Support CLI"
---

Vespa Enterprise イメージには、`vespa-support` という組み込みのコマンドラインツールが含まれています。これは、システムから診断情報を収集するプロセスを簡素化・迅速化し、Vespa チームへのサポート依頼とサポートの受領を容易にするために設計されています。

以下のような場合には、このツールを実行してください:

- Vespa のデプロイメントで予期しない動作やパフォーマンスの低下が発生している場合
- Vespa のサポートチケットを起票または返信する準備をしている場合
- Vespa サポートから診断情報の提供を求められた場合

## ツールへのアクセス

`vespa-support` は、稼働中の任意の Vespa Enterprise コンテナーのシェルで利用できます。アクセスするには、お使いのプラットフォームの標準的な方法でコンテナー内のシェルセッションを開き、ツールが利用可能であることを確認します:

```bash
$ vespa support --help
```

ツールのバージョンとコンテナーのバージョンを確認するには:

```bash
$ vespa support version
```

## コマンド

### vespa support version

`vespa-support` ツールのバージョンと Vespa Enterprise コンテナーのバージョンを表示します。

### vespa support diagnostics sysinfo

コマンドが実行されたノードから、ホストレベルのシステム情報を収集します。`--dest-dir` は必須です。指定しない場合、コマンドは失敗します。

```bash
$ vespa support diagnostics sysinfo --dest-dir <output-directory>
```

### vespa support diagnostics application

現在デプロイされている Vespa アプリケーションの状態を収集します。`--dest-dir` は必須です。指定しない場合、コマンドは失敗します。

```bash
$ vespa support diagnostics application --dest-dir <output-directory>
```

## 収集される内容

### sysinfo

出力は、指定した出力先ディレクトリに `diag-sysinfo.zip` という名前の ZIP ファイルとして書き込まれます。これには、ホストに関する以下の情報が含まれます:

- Vespa のバージョン
- ホスト名、オペレーティングシステム、カーネルバージョン、CPU アーキテクチャー
- CPU のモデルとコア数
- メモリ使用量（合計、空き、利用可能）
- マウントされたファイルシステムごとのディスク使用量（サイズ、空き容量、使用率）
- コンテナー内から見えるネットワークインターフェース、ルーティングテーブル、DNS サーバー、ファイアウォールルール
- ホストレベルの診断メトリクス

### application

出力は、指定した出力先ディレクトリに `diag-application.zip` という名前の ZIP ファイルとして書き込まれます。これには、アプリケーションに関する以下の情報が含まれます:

- 稼働中の Vespa アプリケーションの完全な状態
- アプリケーションレベルの診断メトリクス

## サポートバンドルの作成

以下の手順では、Vespa サポートチームに共有するための一連の診断ファイルを収集する方法を説明します。

<Steps>
<Step title="Vespa Enterprise コンテナー内のシェルセッションを開きます。"/>
<Step title="出力を保存するディレクトリを作成します:">
```bash
$ mkdir /tmp/vespa-diagnostics
```
</Step>
<Step title="システム情報を収集します:">
```bash
$ vespa support diagnostics sysinfo --dest-dir /tmp/vespa-diagnostics
```
</Step>
<Step title="アプリケーションの診断情報を収集します:">
```bash
$ vespa support diagnostics application --dest-dir /tmp/vespa-diagnostics
```
</Step>
<Step title="出力を確認します:">

```bash
$ ls /tmp/vespa-diagnostics
diag-sysinfo.zip
diag-application.zip
```

完了したら、ZIP ファイルをコンテナーからコピーし、サポートチケットに添付してください。
</Step>
</Steps>

## Vespa サポートとの共有

前の手順で生成した ZIP ファイルを、Vespa のサポートチケットに添付してください。まだチケットを起票していない場合は、依頼の送信時にファイルを含めてください。

ファイルが大きすぎて直接添付できない場合は、Vespa のサポートチームが代替のアップロード方法を案内します。
