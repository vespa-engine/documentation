Vespa Operator は、[Operator パターン](https://kubernetes.io/docs/concepts/extend-kubernetes/operator/)の実装であり、Vespa のためのカスタム・オーケストレーション機能で Kubernetes を拡張します。これは `VespaSet` と呼ばれる [Custom Resource Definition](https://kubernetes.io/docs/concepts/extend-kubernetes/api-extension/custom-resources/) に依存しており、Kubernetes ネームスペース内の [ConfigServer](/ja/operations/self-managed/configuration-server) のクォーラムを表します。Vespa Operator は、`VespaSet` リソースとその ConfigServer のデプロイとライフサイクルに責任を持ち、これらが全体として Kubernetes 上の Vespa のインフラストラクチャを構成します。

[アプリケーション・パッケージ](/ja/basics/applications)は、[ConfigServer](/ja/operations/self-managed/configuration-server) にデプロイされて Vespa アプリケーションを作成します。ConfigServer は、アプリケーション・パッケージで指定された設定に基づいて、サービスを個々の Pod として動的にインスタンス化します。アプリケーション・パッケージのデプロイ後も、ConfigServer は Vespa アプリケーションの管理とライフサイクルに責任を持ち続けます。
