ファイルの除外は、Vespa アプリケーションのディレクトリに開発目的でのみ使用され、アプリケーションから直接参照されないファイルが含まれている場合に便利です。

## 配置場所

`.vespaignore` ファイルは、[services.xml](/ja/reference/applications/services/services) と同じ階層に配置する必要があります。異なるパス階層に複数の `.vespaignore` を置くことはサポートされていません。

## 例

これは、アプリケーション・パッケージでほとんど必要とされないファイルやディレクトリを除外する `.vespaignore` ファイルの例です。

```txt
# exclude hidden files and readme
.DS_Store
.gitignore
README.md

# exclude feed input
ext/

# exclude auxiliary scripts
*.py
*.sh
```

## フォーマット

`.vespaignore` のフォーマットは `.gitignore` フォーマットのサブセットで、次のようになっています:

- `#` で始まる行は無視され、コメントとして使用できます
- 空でない各行は、無視するパスのパターンを指定します
- パターンは `services.xml` からの相対パスです
- パターンには、リテラル文字列、または [filepath.Match](https://pkg.go.dev/path/filepath#Match) が受け付けるパターン文字列を指定できます
- `/` で終わる行は常にディレクトリを表します。例えば、パターン `foo/` はディレクトリ `foo` (およびその配下のファイル) にマッチしますが、ファイル `foo` にはマッチしません

否定パターンや再帰的な glob (`**`) などの複雑なルールはサポートされていません。
