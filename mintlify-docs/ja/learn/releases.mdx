## バージョン

Vespa は[セマンティック・バージョニング](https://semver.org/)を使用しています。各リリースは後方互換性があり、2 か月未満前のバージョンを実行しているシステムであれば、稼働中のシステムのライブ・マイグレーションをサポートします。したがって、これはマイナー・バージョン番号の変更となります。すべての新機能は、このようなマイナー・バージョンでリリースされます。おおよそ 2 年ごとに、以前に非推奨とされた機能を削除するメジャー・バージョンの変更を行います。

Java API、Web サービス API、およびすべてのアプリケーション・パッケージの構成要素は、メジャー・リリースを通じてサポートされ、すでに非推奨とマークされている場合にのみ、新しいリリースで削除されます。

非推奨の Java API を使用するとコンパイル時に警告が発生し、非推奨のアプリケーション・パッケージ構成要素を使用するとデプロイ時に非推奨警告が発生します。Java API には 2 つのカテゴリーがあることに注意してください:

- *パブリック API* は互換性の保証があり、コードから参照でき、javadoc にも記載されています
- *エクスポート API* もコードから参照できますが、公開されている Javadoc には含まれず、互換性の保証はありません

パブリックなパッケージを使用していることを確認するには、Javadoc の一覧を確認してください。

さらに、一部のパブリックな Java クラスやメソッドには com.yahoo.api.annotations.Beta タグが付けられています。これらは開発中であり、安定するまで変更される可能性があります。

## 保存されたデータ

Vespa に書き込まれたデータは、隣接するリリース間で互換性があります。セルフホストのシステムでは、Vespa が既存のデータを読み取れるようにするために、大きく飛ばすのではなく、各マイナー・リリースを経由してアップグレードする必要がある場合があります。これはいずれにせよ良いプラクティスです。
