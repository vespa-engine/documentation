*チャンカー*のリファレンス設定: [chunk インデックス式](/ja/reference/writing/indexing-language#chunk)でテキストを分割するコンポーネントです。例:

```bash
indexing: input myTextField | chunk fixed-length 500 | index
```

[チャンクの扱い方ガイド](/ja/rag/working-with-chunks)も参照してください。

## チャンカーコンポーネント

チャンカーは[コンポーネント](/ja/applications/components)なので、独自のチャンカーを追加することもできます:

```xml
<container version="1.0">
    <component id="myChunker"
      class="com.example.MyChunker"
      bundle="the name in artifactId in pom.xml">
        <config name='com.example.my-chunker'>
            <myValue>foo</myValue>
        </config>
    </component>
</container>
```

チャンカーコンポーネントは、[com.yahoo.language.process.Chunker](https://github.com/vespa-engine/vespa/blob/master/linguistics/src/main/java/com/yahoo/language/process/Chunker.java) インターフェースを実装して作成します。[これらの例](https://github.com/vespa-engine/vespa/tree/master/linguistics/src/main/java/ai/vespa/language/chunker)を参照してください。
