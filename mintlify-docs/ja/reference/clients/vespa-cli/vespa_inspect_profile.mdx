### Synopsis

vespa query --profile で事前に取得したプロファイリング結果を検査します

<Note>
**Note:** 

この機能は実験的なものであり、現在開発中です
</Note>
プロファイリング結果は vespa-query-analyzer(vespa インストールの一部)でも分析できます

```bash
vespa inspect profile [flags]
```

### Options

```text
  -h, --help                  help for profile
  -f, --profile-file string   Name of the profile file to inspect (default "vespa_query_profile_result.json")
```
