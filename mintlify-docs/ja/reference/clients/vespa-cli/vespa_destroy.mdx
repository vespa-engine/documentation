### Synopsis

デプロイされた Vespa アプリケーションとそのデータを削除します。

このコマンドは、現在デプロイされているアプリケーションを削除し、そのデータを完全に削除します。

対話的に実行された場合、このコマンドはアプリケーションを削除する前に確認を求めます。非対話的に実行された場合、--force オプションが指定されない限り、このコマンドはアプリケーションの削除を拒否します。

このコマンドは、Vespa Cloud の非プロダクションのデプロイメントの削除にのみ使用できます。プロダクションのデプロイメントの削除方法については [/ja/operations/deleting-applications.html](/ja/operations/deleting-applications) を参照してください。

その他のシステムでは、アプリケーションが使用しているコンテナーを削除することでアプリケーションを破棄します。例: https://github.com/vespa-engine/sample-apps/tree/master/examples/operations/multinode-HA#clean-up-after-testing

```bash
vespa destroy [flags]
```

### 例

```bash
$ vespa destroy
$ vespa destroy -a mytenant.myapp.myinstance
$ vespa destroy --force
```

### オプション

```bash
      --force   Disable confirmation (default false)
  -h, --help    help for destroy
```

### 親コマンドから継承されるオプション

```bash
  -a, --application string   The application to use. Format "tenant.application.instance" - instance is optional (tenant required for cloud targets)
  -C, --cluster string       The container cluster to use. This is only required for applications with multiple clusters
  -c, --color string         Whether to use colors in output. Must be "auto", "never", or "always" (default "auto")
  -i, --instance string      The instance of the application to use
  -q, --quiet                Print only errors
  -t, --target string        The target platform to use. Must be "local", "cloud", "hosted" or an URL (default "local")
  -z, --zone string          The zone to use. This defaults to a dev zone (cloud only)
```
