### 概要

Vespa Cloud コントロール・プレーンとのヘッドレス認証用に、新しい開発者キーを作成します

開発者キーはテナント全体のシークレットであり、Vespa Cloud コントロール・プレーンとのヘッドレスな通信を目的としています。たとえば、継続的インテグレーション・システムからデプロイする場合です。

開発者キーは Vespa CLI のホーム・ディレクトリーに保存されます('vespa help config' を参照)。その後、他のコマンドは必要に応じて開発者キーを自動的に読み込みます。

環境変数によって、使用する開発者キーをオーバーライドすることが可能です。これは継続的インテグレーション・システムで便利です。

キーをインラインで設定する例:

    export VESPA_CLI_API_KEY="my api key"

キーをカスタム・パスから読み込む例:

    export VESPA_CLI_API_KEY_FILE=/path/to/api-key

環境変数で開発者キーをオーバーライドした場合、そのキーが常に使用されることに注意してください。環境変数を通じてテナント固有のキーを指定することはできません。

開発者キーの詳細は [/ja/security/guide.html](/ja/security/guide) を参照してください。

```bash
vespa auth api-key [flags]
```

### 例

```bash
$ vespa auth api-key -a my-tenant.my-app.my-instance
```

### オプション

```bash
  -f, --force   Force overwrite of existing developer key
  -h, --help    help for api-key
```

### 親コマンドから継承されるオプション

```bash
  -a, --application string   The application to use. Format "tenant.application.instance" - instance is optional (tenant required for cloud targets)
  -C, --cluster string       The container cluster to use. This is only required for applications with multiple clusters
  -c, --color string         Whether to use colors in output. Must be "auto", "never", or "always" (default "auto")
  -i, --instance string      The instance of the application to use
  -q, --quiet                Print only errors
  -t, --target string        The target platform to use. Must be "local", "cloud", "hosted" or an URL (default "local")
  -z, --zone string          The zone to use. This defaults to a dev zone (cloud only)
```
