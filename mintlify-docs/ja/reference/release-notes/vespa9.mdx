このドキュメントは、Vespa のメジャーバージョン 8 と 9 の間の変更点を列挙します。[Vespa のバージョン](https://vespa.ai/releases#versions)に記載されているとおり、Vespa の新機能はマイナーバージョンで導入され、メジャーバージョンは互換性を破壊するリリースを示すために使用されます。Vespa 9 は新機能を導入しないため、それに先行する Vespa 8 の各バージョンと同等に安全かつ成熟しています。

注: これは作成中のドキュメントです。Vespa 9 は暫定的に 2026 年第 1 四半期のリリースが予定されています。

## 概要

Vespa 9 における互換性を破壊する変更は、次のカテゴリーに分類されます:

- [デフォルト動作の変更](#changed-defaults)
- [アプリケーション・パッケージの構造と設定](#application-package-changes) - 例えば *schemas* や *services.xml* における非推奨の設定や構文が削除されます。
- [Java API](#java-api-changes) - 非推奨の API が削除されるか、Vespa の[パブリック API](https://javadoc.io/doc/com.yahoo.vespa/annotations/latest/com/yahoo/api/annotations/PublicApi.html) の対象から除外されます。
- [コンテナー実行環境](#container-runtime) - Java のビルド環境および実行環境に対する非互換の変更。
- [HTTP API の変更](#removed-http-api-parameters)
- [削除されたコマンドラインツール](#removed-command-line-tools)
- [削除または名称変更されたメトリクス](#removed-or-renamed-metrics)
- [セキュリティ関連の変更](#security)
- [オペレーティングシステムのサポート](#operating-system)
- 上記のいずれのカテゴリーにも含まれない[その他の変更](#other-changes)。

アプリケーションが Vespa 9 と互換であることを確認するために、アプリケーションの所有者は次を行う必要があります:

- [デフォルトの変更](#changed-defaults)の一覧を確認し、Vespa 8 の動作を維持したい場合は必要なオプションを追加する。
- Vespa 8 に対してコンパイルした際に非推奨警告が出ないことを確認する。
- [アプリケーション・パッケージの変更](#application-package-changes)を確認し、Vespa 8 でのデプロイ時にデプロイ警告が出ないことを確認する。
- [HTTP API の変更](#removed-http-api-parameters)の一覧を確認し、アプリケーションのクライアントを更新する。
- このドキュメントの残りのセクションを確認し、アプリケーションとその環境を適宜更新する。

非推奨の Java API を使用するとコンパイル時に警告が出力され、アプリケーション・パッケージの非推奨事項とコンテナー実行環境に対するほとんどの変更については*デプロイ警告*が出力されます。ホステッド Vespa または Vespa Cloud では、デプロイ警告はアプリケーションのコンソールビューに表示されます。ただし、それ以外の種類の変更については非推奨警告を出す手段がないため、このドキュメントおよびその他の Vespa ドキュメントでのみ説明されます。

以下のセクションでは、Vespa 8 から Vespa 9 へのすべての変更点を詳細に列挙します。

## コンテナー実行環境

### JDK バージョン

Vespa 9 では JDK バージョンが 17 から 25 にアップグレードされます。古い JDK バージョンでビルドされた Java 成果物は、引き続き Vespa 9(JDK 25)と互換性があります。逆は不可能です - Vespa 8(JDK 21)はより新しい JVM バイトコードと互換性がありません。ただし、*javac* の *\--release* オプションを使って古い JDK バージョンをターゲットにすることは可能です。

アプリケーションの OSGi バンドルが、上記一覧の必要な成果物を組み込んでいることを確認してください。成果物は、pom.xml の *dependencies* セクションにスコープ *compile* で追加することで組み込めます。通常、これらの成果物はこれまでスコープ *provided* で使用されてきました。一覧の成果物が直接的または推移的に依存関係として含まれているかどうかを確認するには、`mvn dependency:tree` を使用してください。

例によって、プロジェクトに必要のない依存関係は削除してください。推移的に含まれる依存関係の削除方法については、Maven ドキュメントの [Dependency Exclusions](https://maven.apache.org/guides/introduction/introduction-to-optional-and-excludes-dependencies.html#dependency-exclusions) を参照してください。

*org.json:json* を compile スコープの依存関係として追加する例:

```xml
<dependencies>
  ...
  <dependency>
    <groupId>org.json</groupId>
    <artifactId>json</artifactId>
    <version>20211205</version>
    <scope>compile</scope>
  </dependency>
  ...
</dependencies>
```
