    </tr>

    </tr>

      <td><code>{`/state/v1/metrics`}</code> <code>{`/state/v1/health`}</code> と同じですが、完全なメトリクスセットを返します。メトリクスは <a href="#name" aria-label="name">name</a> と <a href="#values" aria-label="values">values</a> を持ち、<a href="#description" aria-label="description">description</a> と一連の <a href="#dimensions" aria-label="dimensions">dimensions</a> を持つことがあります: <code>{`{`}</code> <code>{`&quot;name&quot;: &quot;content.proton.documentdb.matching.rank_profile.query_setup_time&quot;,`}</code> <code>{`&quot;description&quot;: &quot;Average time (sec) spent setting up and tearing down queries&quot;,`}</code> <code>{`&quot;values&quot;: {`}</code> <code>{`&quot;average&quot;: 0,`}</code> <code>{`&quot;sum&quot;: 0,`}</code> <code>{`&quot;count&quot;: 0,`}</code> <code>{`&quot;rate&quot;: 0,`}</code> <code>{`&quot;min&quot;: 0,`}</code> <code>{`&quot;max&quot;: 0,`}</code> <code>{`&quot;last&quot;: 0`}</code> <code>{`},`}</code> <code>{`&quot;dimensions&quot;: {`}</code> <code>{`&quot;documenttype&quot;: &quot;music&quot;,`}</code> <code>{`&quot;rankProfile&quot;: &quot;default&quot;`}</code> <code>{`}`}</code> <code>{`}`}</code></td>
    </tr>
