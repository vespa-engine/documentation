このドキュメントでは、Vespaが返す `page` 結果フォーマットについて説明します。この結果フォーマットは、[presentation.format](/ja/reference/api/query#presentation.format) が `page` に設定されている場合に使用されます。このフォーマットは通常、[ページ・テンプレート](/ja/reference/querying/page-templates)とともに使用されます。

このフォーマットのタグを以下で説明します。サブタグは、ここに記載された順にレンダリングされます。このフォーマットは _オープン_ であり、すべてのパーサーは、ここで言及されていない属性と子タグを無視しなければなりません。

## \<page\>

ページ結果のルート・タグ: ページの単一のトップレベル・セクションです。

<table className="vespa-table">
  <thead>
    <tr>
      <th>属性</th>
      <th>説明</th>
      <th>存在</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>version</td>
      <td>このフォーマットのバージョン - 現在は1.0です。</td>
      <td>常に</td>
    </tr>
    <tr>
      <td>layout</td>
      <td>このページに使用するトップレベル・レイアウトの名前。</td>
      <td>使用するページ・テンプレートで指定されている場合。</td>
    </tr>
  </tbody>
</table>

通常許可されるサブタグについては、[section](#<section>) を参照してください。

    </tr>
  </tbody>
</table>

## \<hit\>

単一の結果コンテンツ・アイテムです。

<table className="vespa-table">
  <thead>
    <tr>
      <th>属性</th>
      <th>説明</th>
      <th>存在</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>relevance</td>
      <td>このアイテムの関連度 - 通常は0から1の間の正規化された数値。</td>
      <td>常に</td>
    </tr>
    <tr>
      <td>source</td>
      <td>このヒットを生成したソースの名前。</td>
      <td>常に</td>
    </tr>
    <tr>
      <td>type</td>
      <td>このヒットの型識別子のスペース区切りリスト。</td>
      <td>ヒットに型が設定されている場合。</td>
    </tr>
  </tbody>
</table>

サブタグ:

ヒットは、含んでいるフィールドごとに1つのサブタグを持ちます。フィールド名がタグの名前になり、フィールドの内容のtoStringがタグの内容になります。

## \<group\>

ネストされたヒットを含む[ヒット](#<hit>)です。ヒットを階層的に整理するために使用します。[hit](#<hit>) と同じ属性とサブタグを持ちますが、ネストされた [hit](#<hit>) タグと [group](#<group>) タグも含められます。

## 例

上部に2つのカラムでレンダリングされるべきページです。

```xml expandable
<page version="1.0">

    <renderer name="two-column"/>

    <section region="left">
        <source url="http://host:port/resource/[news article id]"/>
        <renderer name="articleBodyRenderer">
            <parameter name="color">blue</parameter>
        </renderer>
    </section>

    <section region="right">
        <renderer name="multi-item-column">
            <parameter name="items">3</parameter>
        </renderer>
        <section region="1">
            <renderer for="newsImage" name="newsImageRenderer"/>
            <renderer for="news" name="articleRenderer"/>
            <renderer for="image" name="imageRenderer"/>
            <content>
                <hit relevance="1.0" source="news">
                    <id>news-1</id>
                </hit>
                <hit relevance="0.5" source="news">
                    <id>news-2</id>
                </hit>
            </content>
        </section>
        <section region="2">
            <source url="http://host:port/consumption-widget"/>
            <renderer name="identityRenderer"/>
        </section>
        <section region="3">
            <renderer name="htmlRenderer"/>
            <content>
                <hit relevance="1.0" source="htmlSource">
                    <id>htmlSource-1</id>
                </hit>
            </content>
        </section>
    </section>
</page>
```
