*validation-overrides.xml* は、[アプリケーション・パッケージ](/ja/reference/applications/application-packages)のルート (つまり [services.xml](/ja/reference/applications/services/services) と同じ場所) に追加され、通常であればバリデーションに失敗するデプロイメントの続行を許可します。メッセージには、そのバリデーションが何に関するものか、およびバリデーションオーバーライドの追加方法が説明されます。

バリデーションは、プロダクションのインスタンスを誤って破損させることを防ぎます。オーバーライドが有用なのは、例えばアプリケーションがまだプロダクションに入っていない場合や、特定のフィールドのデータの不整合や損失による影響が問題ないと考えられる場合です。

スキーマ変更の詳細については、[スキーマリファレンス](/ja/reference/schemas/schemas#modifying-schemas)を参照してください。

## 構造

```xml
<validation-overrides>
    <allow until="iso-8601-date" comment="Optional note">validation-id</allow>
</validation-overrides>
```

`allow` タグはいくつでも記述できます。例:

```xml
<validation-overrides>
    <allow
        until="2025-01-31"
        comment="Reduce to needed cluster size after benchmarking">resources-reduction</allow>
    <allow
        until="2025-02-03">field-type-change</allow>
</validation-overrides>
```

## allow

`allow` タグは、特定のバリデーションを期間限定で無効化するもので、単一のバリデーション ID を含みます。未知の ID を持つ `allow` タグは無視されます。
